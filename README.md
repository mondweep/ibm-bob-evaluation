# IBM Bob evaluation

A structured, 30-day evaluation of IBM Bob (IBM's AI coding agent, IDE and Bob Shell CLI) using the free trial.

- [EVALUATION_PLAN.md](EVALUATION_PLAN.md): goal, what Bob is, trial terms, criteria, scoring method, Bobcoin budget
- [tasks/TASKS.md](tasks/TASKS.md): the 12 test tasks with setup and acceptance checks
- [SCORECARD.md](SCORECARD.md): scoring anchors and the sheet to fill in
- [results/](results/): run log, terms check, and the final recommendation

Start with section 3 of the plan (ground rules) before installing anything: run Bob in an isolated environment and keep overage billing off.
